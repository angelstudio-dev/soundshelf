# 功能对照与取舍

| 功能 | 状态 | 备注 |
| --- | --- | --- |

| 按作者、合集、系列浏览 | ✅ | 合集由书源同步生成 |
| 下载队列与离线收听 | 部分 | Web PWA 缓存 / App 文件系统；小程序受微信配额限制 |
| 片段书签和笔记 | ✅ | 服务端持久化 |
| 播放历史、统计、连续天数 | ✅ | 会话表驱动 |

| 每本书独立倍速 | ✅ | 保存至用户设置 |
| 睡眠定时（时间 / 章节） | ✅ | 时间、本章结束、下一章结束 |

## 明确不做

- 复制 Prologue 的品牌名称、图标、界面素材或专有代码
- 内置、出售或分发任何书籍内容
- 在微信小程序中声称支持 Apple Watch / CarPlay / Siri
